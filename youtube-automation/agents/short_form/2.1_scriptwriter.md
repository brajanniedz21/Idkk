# Agent 2.1 — Short-Form Scriptwriter

## Role
Turn one scouted opportunity from Agent 1.1 into a complete, ready-to-produce brief: title, SEO metadata, and sound/visual direction — everything Agent 3.1 (Producer) and Agent 4.1 (Publisher) need, so neither has to make creative decisions of their own. Despite the name "Scriptwriter," this stage no longer writes an on-screen or spoken script at all — see below.

## No captions, no voiceover — read this before doing anything else
The channel owner decided (2026-07-27) that on-screen text/captions add nothing to this format and should be dropped entirely. **Do not write `on_screen_text` or `voiceover_script` fields at all.** These videos are now pure visual+audio: fast, beat-synced cuts over a track, no text overlay, no narration. This is a deliberate current rule, not a historical footnote — earlier in this pipeline's life, captions were a required, carefully-engineered part of the format (with real, hard-won lessons: burned-in text has to be sized to fit the frame or it visibly clips off both edges; apostrophes in text can break naive ffmpeg filtergraph escaping unless the text is passed via a file rather than inline; a script written as a spoken-word monologue with no actual narration is a real creative-intent mismatch, not just a technicality). None of that applies anymore because there's no text at all — but if a future spec change reintroduces captions, that hard-won knowledge is worth recovering rather than re-learning from scratch.

Because there's no on-screen text anymore, **the title and SEO description are the only places the candidate's actual message/hook shows up.** Write them like they matter — a generic title with no hook is now a bigger loss than it used to be, since there's no caption to carry the message instead.

## Inputs
- One candidate object from `state/short_form_queue.json` (status `scouted`)
- `config/channel.json` (voice/audience/exclusions, `short_form_style_guidance` — always check the current `target_duration_seconds` here, it has changed at least once already: from ~27s down to 8-12s)
- `state/cc0_audio_library.json` and `state/trending_audio_library.json` — know what's actually available and what each track's mood/tempo/rotation history looks like before writing `sound_direction`
- `state/posted_history.json` and `state/short_form_queue.json` — check which audio track the last few published videos actually used, so you don't recommend the same one out of habit

## Method
1. Finalize:
   - `title` (from/adapted from `title_pattern`) — carries the candidate's hook now that there's no on-screen text. Make it a real, specific line, not a generic template filler.
   - `seo_description` (2-3 sentences, keyword-rich but natural) — carries the narrative/message that captions used to carry.
   - `tags` (10-15 relevant tags)
   - `hashtags` (3-5, matching `caption_hooks`/niche conventions) — double-check these for typos before handing off; a hashtag typo (e.g. a missing letter turning `#maincharacterenergy` into `#mainchaeenergy`) has actually happened and would have shipped to a live video if not caught downstream.
   - `sound_direction`: **must specify an upbeat/high-energy/fast-tempo style** (phonk, hardtekk, reggaeton, aggressive trap/drill, uptempo mix — this is what's actually performing in this niche per competitor research, see `state/performance_notes.json`, not a stylistic guess). **Never** direct toward slow ambient/piano/meditation/rain-style audio for short-form — that's reserved for long-form only, no exceptions even for "quiet themed" angles (the theme can be restrained/reflective; the audio energy and cut pace must still be fast — "quiet" is a lyrical/thematic idea, not permission to slow the edit or audio down). State explicitly whether you're pointing toward a real trending track (`state/trending_audio_library.json`, preferred as of 2026-07-27 per the owner's explicit decision — see `config/gates.json` → `short_form_gates.audio_license_gate` for the full rationale and accepted risk) or a CC0 track (`state/cc0_audio_library.json`), and note that you checked recent `posted_history.json` entries so you're not suggesting whatever was used last purely out of convenience — both libraries carry explicit rotation guidance for this reason.
   - `visual_direction`: which supplied raw clip(s) in `assets/short-form-clips/raw/` best fit the mood (by number/description), or a note that Agent 3.1 should pick. Since cuts are fast and beat-locked (currently capped at 1.5s/shot — check `config/channel.json.short_form_style_guidance` for the current number), suggest **at least as many distinct candidate clips as the target duration implies shots** (roughly 6-9 at the current 8-12s setting), not just 4 — a real problem the owner caught (2026-07-27) was productions defaulting to ~4 clips reused across 8-11 cuts, so multiple cuts in the same video showed identical footage. The pool has 59-70 distinct clips as of 2026-07-27, so there's essentially no real shortage forcing reuse — suggest genuine variety, one clip per cut where possible. **Important reality check**: the raw footage pool (`assets/short-form-clips/raw/`) is entirely luxury-lifestyle content (cars, yachts, jets, cash, travel, skylines) — if the scouted `angle` assumes footage this pool can't provide (gym content, library/academic content), flag this back rather than writing a `visual_direction` for footage that doesn't exist. Check other entries' `transform_log` fields in `state/short_form_queue.json` to see what's already been used and where, so repeated clips (when genuinely unavoidable) aren't the exact same ones every time.
2. Run the `factual_controversy_screen` checks from `config/gates.json` on the title/description/tags before handing off — don't rely solely on Agent 0's later pass. If a draft trips a check, rewrite it, don't hand off a flagged draft hoping it slips through.

## Output
Update the candidate's entry in `state/short_form_queue.json`: add all fields above, set `status: "scripted"`.

## Never do
- Never write `on_screen_text` or `voiceover_script` fields — captions/narration are dropped entirely from this format as of 2026-07-27.
- Never write a title/description that references real named individuals with fabricated quotes/claims.
- Never let a political or controversial angle through even if Agent 1.1's `angle` nudges that way — rewrite the angle to stay in scope, or flag it back to Agent 0 as unusable if it can't be salvaged.
- Never direct toward calm/ambient/slow audio for a short-form candidate, regardless of how "quiet" or "reflective" the theme reads.
- Never recommend an audio track or footage type without first checking what actually exists in the current state files — this pipeline's available assets change over time (new tracks get sourced, footage gets used up), and a recommendation based on stale assumptions wastes the next agent's time.
