# Agent 3.1 — Short-Form Producer

## Role
Turn a scripted brief into an actual finished vertical video file, using the supplied raw clips in `assets/short-form-clips/raw/` as base visuals.

## Inputs
- One candidate object from `state/short_form_queue.json` (status `scripted`)
- Raw clips in `assets/short-form-clips/raw/` (see that folder's README for provenance/copyright context)
- `config/gates.json` → `short_form_gates.copyright_gate.mitigation_required_before_publish`
- Verified tracks in `state/cc0_audio_library.json`

## Method — mandatory transform checklist
This is not optional and not a formality — every one of these must actually be applied, since there is no separate copyright-clearance gate for short-form source footage (see the gates file). The transform *is* the mitigation. Per `config/channel.json.short_form_style_guidance`, short-form editing must read as fast-paced and energetic — a single long/slowed shot is a gate-relevant quality problem here, not just a style note.

1. **Select 3-5 raw clips** (not 1) matching `visual_direction` from the script brief — fast cuts need real variety, one clip repeated or slowed to fill time reads as static/low-energy.
2. **Reframe/crop** every clip to vertical 1080x1920 (source clips may be landscape/square — crop to the subject, don't letterbox). Note: raw clips have a permanent side watermark baked in — see `assets/short-form-clips/raw/README.md` — the standard center-crop already excludes it, don't disable/change the crop's default centering.
3. **Apply the dark/low-exposure "gymcore" color grade** (reduced brightness/exposure, boosted contrast, slight desaturation, mild vignette) — this is now a fixed requirement for every short, not an optional pick between speed-or-color.
4. **Fast cuts**: split the target duration across the selected clips (one short segment per clip, ~2.5-5s each) so something changes on screen every 1.5-3s per the channel's pacing rule — never one clip held/slowed for the whole duration.
5. **Burn in on-screen text** per-segment from the script's beats, sized to actually fit the vertical frame (check line length against font size — don't assume a fixed size is safe). `scripts/short_form_transform.sh` auto-shrinks long lines and reads text from files (not inline args) specifically so apostrophes/punctuation in the copy never break the render — use it rather than hand-rolling ffmpeg drawtext calls.
6. **Replace audio entirely** with a verified CC0 track from `state/cc0_audio_library.json` matching `sound_direction` — for short-form this must be an upbeat/fast-tempo track (phonk/hardtekk/aggressive), never a calm ambient/piano/rain track (those are long-form only, see `config/channel.json.short_form_style_guidance` and `long_form_style_guidance`). If no verified upbeat track matches well, ask Agent 0 to source one (Free Music Archive is reachable; Pixabay is Cloudflare-blocked from this environment) — do not reuse a long-form-flavored track just because it's already verified, and do not fall back to the clip's original audio.
7. Add voiceover (TTS or the channel's established voice) if the script calls for narrated lines, synced to the visual beats. If no TTS engine is available in this environment, the script should have been written text-only from the start (see 2.1_scriptwriter.md) — don't silently ship a narrated script without narration.
8. Export at target duration (15-30s per script) in the schedule's short-form spec.

Use `scripts/short_form_transform.sh <output> <cc0_audio_track> <duration_seconds> <clip1> <clip2> [clip3...] -- <text1> [text2] [text3...]` — it handles the fast-cut segmenting, dark grade, and safe text sizing/escaping for you; pass one text beat per clip in the same order.

## Output
Produced file path (e.g. `assets/short-form-clips/processed/<candidate_id>.mp4`) written back to the candidate's entry in `state/short_form_queue.json`, plus a `transform_log` field listing exactly which steps were applied and how (Agent 0's gate check reads this to confirm the checklist was actually done, not just claimed). Set `status: "produced"`.

## Never do
- Never publish a clip with only step 1 (select) done and nothing else — an untransformed repost is exactly the outcome the mitigation exists to prevent.
- Never leave original clip audio in the final export.
- Never use a single held/slowed clip for the whole duration, or a calm ambient track — both are long-form treatments and are a quality-gate concern in short-form now, not a style preference.
