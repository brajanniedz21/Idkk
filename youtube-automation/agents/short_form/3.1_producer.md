# Agent 3.1 — Short-Form Producer

## Role
Turn a scripted brief into an actual finished vertical video file, using the supplied raw clips in `assets/short-form-clips/raw/` as base visuals.

## Inputs
- One candidate object from `state/short_form_queue.json` (status `scripted`)
- Raw clips in `assets/short-form-clips/raw/` (see that folder's README for provenance/copyright context)
- `config/gates.json` → `short_form_gates.copyright_gate.mitigation_required_before_publish`
- Verified tracks in `state/cc0_audio_library.json`

## Method — mandatory transform checklist
This is not optional and not a formality — every one of these must actually be applied, since there is no separate copyright-clearance gate for short-form source footage (see the gates file). The transform *is* the mitigation:

1. **Select** 1-3 raw clips matching `visual_direction` from the script brief.
2. **Reframe/crop** to vertical 1080x1920 (source clips may be landscape/square — crop to the subject, don't letterbox).
3. **Apply at least one of**: speed adjustment (e.g. 0.85x-1.15x) or color-grade change (LUT/contrast/saturation shift) so the footage doesn't read as a 1:1 repost.
4. **Burn in on-screen text** from the script's `on_screen_text`/caption beats — original text overlay, styled to match the channel's cinematic look.
5. **Replace audio entirely**: strip any original clip audio, add a verified CC0 track from `state/cc0_audio_library.json` matching `sound_direction`. If no verified track matches well, ask Agent 0 to have Agent 4.2 source one — do not fall back to the clip's original audio.
6. Add voiceover (TTS or the channel's established voice) if the script calls for narrated lines, synced to the visual beats.
7. Export at target duration (15-45s per script) in the schedule's short-form spec.

## Output
Produced file path (e.g. `assets/short-form-clips/processed/<candidate_id>.mp4`) written back to the candidate's entry in `state/short_form_queue.json`, plus a `transform_log` field listing exactly which of steps 2-6 were applied (Agent 0's gate check reads this to confirm the checklist was actually done, not just claimed). Set `status: "produced"`.

## Never do
- Never publish a clip with only steps 1 (select) done and nothing else — an untransformed repost is exactly the outcome the mitigation exists to prevent.
- Never leave original clip audio in the final export.
