# Agent 3.2 — Animator

## Role
Take Agent 2.2's static generated image and add subtle ambient motion so the long-form video isn't a dead static frame for hours — light rain drift, slow zoom/parallax, flickering light, drifting clouds, etc., matched to the image's theme. This is a mood-preservation stage, not a creative-license one: the goal is "not static," not "an interesting animation in its own right."

## Inputs
- Image path from `state/long_form_queue.json` (status `image_sourced`)
- `visual_theme`/`mood` from the same candidate for motion-style matching

## Method
1. Pick a motion treatment matching the theme (e.g. rain-streaked window → animated rain overlay + very slow parallax drift; fireplace scene → flickering light animation; city skyline → slow subtle pan/zoom or drifting light dots). The motion should be something a viewer would only consciously notice if they were looking for it — the ambient background should read as calm and mostly-still at a glance.
2. Use ffmpeg filters (or a short Remotion/compositing pass, whichever is set up in `scripts/`) to produce a short seamless loop segment (10-60 seconds) with the motion applied — this loop segment is what Agent 5 will repeat to fill the target runtime (potentially for hours), so **it must loop with zero visible seam or jump-cut at the wrap point.** This is the single most important technical requirement of this stage: a seam that's barely noticeable once becomes glaringly obvious repeated dozens or hundreds of times over a multi-hour video.
3. Keep motion genuinely subtle — the point is "not static," not a distracting animation. A useful test: does a single still frame grabbed at a random timestamp still read as the intended still-image aesthetic (the kind of frame that would work fine as a thumbnail)? If the motion is strong enough that a random frame looks mid-action or jarring, it's too much.
4. Export the loop segment (e.g. `assets/long-form/output/<candidate_id>_loop_segment.mp4`), silent (audio comes from Agent 4.2/5, mixed independently in the assembly stage — don't bake any audio into this file).

## Output
Update candidate entry in `state/long_form_queue.json` with `animated_loop_path`, set status to `animated`.

## Never do
- Never ship a loop segment with a visible seam/jump at the loop point — Agent 5 will be repeating this dozens/hundreds of times over an hour+, so any seam becomes very noticeable. Verify by watching (or frame-sampling) the exact transition point from the segment's end back to its start before calling this done.
- Never make the motion so strong it stops reading as an ambient background (this isn't an action clip, and the audience for this format specifically wants a calm, unobtrusive visual to work/study/relax against).
- **Never crop a long-form source image down to make a reused image "feel distinct" (owner direction, 2026-07-28).** Long-form source images are already small (owner-supplied stills around 700-750px wide) before being upscaled to 1920x1080 — cropping them further throws away resolution and makes the output blurrier, not more distinct. This is the opposite of short-form, where cropping the raw clip to vertical is a *required* part of the copyright-mitigation transform (see `config/gates.json` `short_form_gates.copyright_gate` and `agents/short_form/3.1_producer.md`) — that rule does not apply here. When a source image must be reused across two candidates, differentiate them through motion (a different pan/zoom direction or amplitude) and color grade/mood instead, at the image's full original resolution.
