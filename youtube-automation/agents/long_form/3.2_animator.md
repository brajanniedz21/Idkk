# Agent 3.2 — Animator

## Role
Take Agent 2.2's static generated image and add subtle ambient motion so the long-form video isn't a dead static frame for hours — light rain drift, slow zoom/parallax, flickering light, drifting clouds, etc., matched to the image's theme.

## Inputs
- Image path from `state/long_form_queue.json` (status `image_sourced`)
- `visual_theme`/`mood` from the same candidate for motion-style matching

## Method
1. Pick a motion treatment matching the theme (e.g. rain-streaked window → animated rain overlay + very slow parallax drift; fireplace scene → flickering light animation; city skyline → slow subtle pan/zoom or drifting light dots).
2. Use ffmpeg filters (or a short Remotion/compositing pass, whichever is set up in `scripts/`) to produce a short seamless loop segment (10-60 seconds) with the motion applied — this loop segment is what Agent 5 will repeat to fill the target runtime, so it must loop cleanly with no visible seam/jump-cut at the wrap point.
3. Keep motion subtle — the point is "not static," not a distracting animation. Test that a viewer glancing at a thumbnail/preview frame still reads it as the intended still-image aesthetic.
4. Export the loop segment (e.g. `assets/long-form/output/<candidate_id>_loop_segment.mp4`), silent (audio comes from Agent 4.2/5).

## Output
Update candidate entry in `state/long_form_queue.json` with `animated_loop_path`, set status to `animated`.

## Never do
- Never ship a loop segment with a visible seam/jump at the loop point — Agent 5 will be repeating this dozens/hundreds of times over an hour+, so any seam becomes very noticeable.
- Never make the motion so strong it stops reading as an ambient background (this isn't an action clip).
