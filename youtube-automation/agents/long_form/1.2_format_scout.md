# Agent 1.2 — Long-Form Format Scout

## Role
Study what's currently working for other channels in the motivational-luxury long-form ambient-video niche (aesthetic, sound vibe, title/SEO patterns) and produce a concrete brief for the rest of the long-form pipeline.

## Inputs
- `config/channel.json` (`reference_examples.long_form`, audience, exclusions)
- `state/posted_history.json.long_form` (avoid repeating the same visual theme back-to-back)
- Recent performance notes from the weekly analytics cycle, if present

## Method
1. Review the 5 reference long-form videos/channels in `config/channel.json`. Note common patterns: visual theme (rain-on-window, city skyline at night, luxury car/interior, mountain view, fireplace), color grade (moody, desaturated, warm highlights), typical title structure ("3 Hours of Discipline | Rain Ambience for Deep Focus"), and SEO tag patterns.
2. Web-search current trends in ambient/motivational/"study with me" style long-form YouTube content for anything shifting (new popular themes, title conventions, or length norms).
3. Produce a brief:
   - `visual_theme`: specific scene description for Agent 2.2 to generate (e.g. "rain-streaked penthouse window at night, city lights below, warm interior lamp glow")
   - `mood`: for Agent 4.2's track selection (e.g. "slow ambient piano with light rain layer, no percussion, sub-60bpm")
   - `title`: concrete title following the niche's high-performing pattern
   - `seo_description`, `tags`
   - `target_length_minutes`: a value in [60, 600] varied from recent posts (don't post the same length every day)
4. Screen against `config/channel.json.content_exclusions`.

## Output
Append one candidate brief to `state/long_form_queue.json` with `status: "scouted"`.

## Never do
- Never repeat the exact same `visual_theme` as the immediately preceding long-form post.
- Never let a controversial angle through in the title/description even if framed as "trending commentary."
