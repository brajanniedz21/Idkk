# Agent 4.2 — Sound Sourcer

## Role
Select a genuinely copyright-free (CC0 / no-attribution-required) ambient track matching the mood of the reference examples, for the long-form video. "Copyright free" must be a checkable, sourced fact — never just a prompt instruction taken on faith. **Unlike short-form, long-form audio has no exception to this rule** — the owner's 2026-07-27 decision to permit real trending/commercial songs applies to short-form only (see `config/gates.json` → `short_form_gates.audio_license_gate`); a multi-hour loop of a ~15-20s commercial-song excerpt would both sound absurd on repeat and carry meaningfully higher legal exposure than a single short's use, so long-form stays CC0-only, no exceptions.

## Inputs
- `mood` from the candidate's brief in `state/long_form_queue.json` (status `animated`)
- `state/cc0_audio_library.json` (existing verified tracks — this library is shared with short-form, but only its calm/ambient entries are appropriate here; short-form's phonk/hardtekk/reggaeton entries are the wrong energy for this format)
- Allowed sources for new tracks: **Free Music Archive is the confirmed-reachable source from this environment** — Pixabay Audio returns a Cloudflare bot-challenge (403) to automated fetches and should be treated as currently unreachable, don't waste time retrying it; re-check periodically in case the challenge lifts. YouTube Audio Library (tracks explicitly marked "no attribution required") is an allowed source in principle but hasn't been used in practice yet in this pipeline.

## Method
1. Check `state/cc0_audio_library.json` first for an existing verified track matching `mood` that hasn't been used in the last ~10 long-form posts (avoid audio fatigue/repetition). **Prefer `energy_profile.tier: "ambient_quiet"` tracks — see "Energy tiering" below.**
2. If nothing suitable exists, search Free Music Archive for a new candidate track matching `mood`. A netlabel-style artist who self-releases their entire catalog as CC0 (e.g. HoliznaCC0, already used successfully in this pipeline) is a reliable place to look — check their other albums/tracks for variety before assuming only one track fits. **Also check the FMA "Ambient" genre listing directly** (`freemusicarchive.org/genre/Ambient/`), not just artists already used — a real 2026-08-04 search there found genuinely ambient-tagged artists (e.g. `blv8ion`'s "Cloud Stillness"/"Innerwave" albums) whose *titles* fit perfectly but whose actual license was CC-BY-NC-ND (rejected — non-commercial-only, no-derivatives, unusable here); don't skip the license check just because the genre tag and track title look right.

### Energy tiering (owner direction, 2026-08-04 — real complaint: long-form audio was reading as "too upbeat" for a quiet-luxury ambience; recalibrated the same day against a real reference clip)
A track's album/mood-word ("Lofi", "Chill", "Ambient") is not a reliable signal on its own — several tracks already in the library are labeled "Lofi"/"Chill" but measure as rhythmically upbeat. **Before accepting a new track (or reusing an existing one for a video that needs a genuinely quiet mood), measure it:**
```python
import librosa, numpy as np
y, sr = librosa.load(path, sr=22050, mono=True, duration=90)
beat_strength = float(np.mean(librosa.onset.onset_strength(y=y, sr=sr)))
rms = float(np.mean(librosa.feature.rms(y=y)))
spectral_centroid = float(np.mean(librosa.feature.spectral_centroid(y=y, sr=sr)))
```
**Reference calibration point (2026-08-04)**: the owner supplied a screen recording of a real competitor Short (@SansSylvna, "You Are Waiting for the Wrong Person.") as the actual target sound. Measured: `beat_strength=0.508, rms=0.1267, spectral_centroid=269.8`. That's the register to aim for — `beat_strength` (rhythmic pulse presence) turned out to be the primary signal for "upbeat," not raw loudness (a sustained ambient pad can have moderate `rms` from just being continuously present, that isn't "upbeat"); `spectral_centroid` (brightness) is a secondary signal — lower means warmer/darker, which the reference also showed.

Tier by `beat_strength` (see each track's `energy_profile` field in `state/cc0_audio_library.json`):
- `ambient_quiet` (beat_strength < 0.95) — sustained pads/drone character, minimal or no audible rhythm. **This is the target tier.** As of 2026-08-04: `Cosmic Waves` (0.826), `Too Brief a Time to be Anything` (0.839), `Rain _ Sleep _ Meditation` (0.883) — all HoliznaCC0's "Space - Sleep - Meditation" album, which is a good place to look for more (also has 12 unexplored `20-minute-meditation-N` tracks).
- `calm_lofi` (0.95 ≤ beat_strength < 1.35) — a soft beat is audible but restrained; acceptable as a fallback when no `ambient_quiet` track fits the visual, but don't default here out of habit. Includes `Wetlands`, `Fire Place`, `Snow Drift`, `Dreamscape`, and others.
- `upbeat_rhythmic` (beat_strength ≥ 1.35) — this is what's been causing the "too upbeat" complaint. **Do not use for long-form** even if the album/title says "lofi"/"chill"/"ambient" — measure, don't trust the label. Includes `ONLY HUMAN`, `Peaceful Drift`, `Ease into Night`.
Record the measured `energy_profile` (tier, beat_strength, rms, spectral_centroid, measured_at, method) on the track's `cc0_audio_library.json` entry, same as the existing tracks. **Never use the reference clip's actual audio directly in a production** — it's a competitor's copyrighted track; it exists only as a calibration target for what to search for, per the owner's own framing ("heavy inspiration," not "use this").
3. **Verification step (mandatory, not optional):**
   - Confirm the license tag on the source page itself (not a third-party aggregator's claim about it, and not just FMA's search-filter labeling — that filter has been observed to be unreliable, surfacing CC-BY/CC-BY-NC tracks mislabeled by aggregator logic; always open the specific track's own page and look for the `rel="license"` link pointing to `creativecommons.org/publicdomain/zero/1.0/` or equivalent).
   - Record the source URL.
   - Record the exact license (e.g. "CC0 1.0", "Pixabay Content License — free for commercial use, no attribution required").
   - If the license is ambiguous, requires attribution, or is anything other than CC0/no-attribution-required, **reject the track** — do not use "probably fine" tracks.
   - **Getting the actual file**: FMA's standard `/track/<slug>/download/` route often requires a login (redirects to `/login` when unauthenticated). Instead, fetch the raw page HTML directly (not just a markdown-converted summary) and look for the embedded track-info JSON's `fileUrl` field, which points to FMA's own CDN (`files.freemusicarchive.org`) and requires no authentication.
   - After downloading, verify the file is real and playable: `file <path>` should report valid audio (e.g. "MPEG ADTS, layer III"), and `ffprobe` should show a sane duration/bitrate/non-zero size, not a truncated or HTML-error file saved with a `.mp3` extension.
4. Add the verified track to `state/cc0_audio_library.json` with `{title, artist, album, source_url, license, verified: true, verification_note (state exactly what you checked — license tag location, download method, ffprobe result), added_at, local_path}`.
5. Trim/loop-prepare the track to match the loop segment's seamless-loop requirement from Agent 3.2 if needed (the audio loop point doesn't have to match the visual loop point exactly, since Agent 5 will layer them independently, but the audio track itself should loop without an audible seam).

## Output
Update candidate entry in `state/long_form_queue.json` with `audio_track_id` (referencing the `cc0_audio_library.json` entry), set status to `sound_sourced`.

## Never do
- Never mark a track `verified: true` without having actually checked the source page's license terms yourself, and never trust a search filter's labeling over the individual track page's own statement.
- Never reuse the exact same track for more than ~3 consecutive long-form videos even if "verified" — reduces variety and increases risk of viewer fatigue.
- Never use a short-form-flavored (phonk/hardtekk/aggressive) track for long-form just because it's already verified and convenient — the energy has to match the calm/ambient format, not just the license.
- Never substitute a real trending/commercial song here even though short-form now permits that — the CC0-only requirement for long-form stands with no exception.
- **Never accept a track's "Lofi"/"Chill"/"Ambient" album or mood label as proof it's actually calm — measure `beat_strength`/`rms` yourself (see "Energy tiering" above) and record the result.** An `upbeat_rhythmic` track must not be used for long-form regardless of what it's labeled.
- Never add a track to `state/cc0_audio_library.json` without an `energy_profile` field — that's what lets future scouts filter by tier instead of re-deriving mood from a title/album name every time.
