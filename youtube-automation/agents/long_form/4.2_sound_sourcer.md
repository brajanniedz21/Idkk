# Agent 4.2 — Sound Sourcer

## Role
Select a genuinely copyright-free (CC0 / no-attribution-required) ambient/phonk track matching the mood of the reference examples, for the long-form video. "Copyright free" must be a checkable, sourced fact — never just a prompt instruction taken on faith.

## Inputs
- `mood` from the candidate's brief in `state/long_form_queue.json` (status `animated`)
- `state/cc0_audio_library.json` (existing verified tracks)
- Allowed sources for new tracks: Free Music Archive (CC0-filtered search), Pixabay Audio, YouTube Audio Library (tracks explicitly marked "no attribution required")

## Method
1. Check `state/cc0_audio_library.json` first for an existing verified track matching `mood` that hasn't been used in the last ~10 long-form posts (avoid audio fatigue/repetition).
2. If nothing suitable exists, search the allowed sources for a new candidate track matching `mood`.
3. **Verification step (mandatory, not optional):**
   - Confirm the license tag on the source page itself (not a third-party aggregator's claim about it).
   - Record the source URL.
   - Record the exact license (e.g. "CC0 1.0", "Pixabay Content License — free for commercial use, no attribution required").
   - If the license is ambiguous, requires attribution, or is anything other than CC0/no-attribution-required, **reject the track** — do not use "probably fine" tracks.
4. Add the verified track to `state/cc0_audio_library.json` with `{title, source_url, license, verified: true, verification_note, added_at}`.
5. Trim/loop-prepare the track to match the loop segment's seamless-loop requirement from Agent 3.2 if needed (the audio loop point doesn't have to match the visual loop point exactly, since Agent 5 will layer them independently, but the audio track itself should loop without an audible seam).

## Output
Update candidate entry in `state/long_form_queue.json` with `audio_track_id` (referencing the `cc0_audio_library.json` entry), set status to `sound_sourced`.

## Never do
- Never mark a track `verified: true` without having actually checked the source page's license terms yourself.
- Never reuse the exact same track for more than ~3 consecutive long-form videos even if "verified" — reduces variety and increases risk of viewer fatigue on repeated Content ID-adjacent checks.
