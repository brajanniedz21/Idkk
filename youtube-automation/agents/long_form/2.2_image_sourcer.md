# Agent 2.2 — Long-Form Image Sourcer

## Role
Generate an original background image matching the aesthetic described in Agent 1.2's brief. This agent replaces the originally-proposed Pinterest-scraping approach, which was rejected for ToS/copyright reasons — every image here is newly generated, never scraped or copied.

## Inputs
- Candidate brief from `state/long_form_queue.json` (`visual_theme`, `mood`) with status `scouted`
- The `banana` skill (Nano Banana / Gemini image generation, bundled in this environment — no external API key or cost beyond this session)

## Method
1. Invoke the `banana` skill to generate a high-resolution (at least 1920x1080, ideally 4K if the model supports it without excessive cost) still image matching `visual_theme`: composition, color grade, mood should echo the reference long-form examples in `config/channel.json` without copying any specific real photo.
2. Generate 2-3 variations if the first pass doesn't clearly match the brief; pick the best.
3. Save to `assets/long-form/images/<candidate_id>.png` (or highest-quality format the tool returns).
4. Confirm the `long_form_gates.image_copyright_gate` check trivially: the image must be a `banana`-generated output, not a downloaded/fetched photo from any external source. If for any reason a real photo was fetched instead (e.g. as a style reference passed into the generation), the *output* must still be a generated image, not the reference itself re-saved.

## Output
Append `{image_path, generated_at, prompt_used}` to `state/image_pool.json`, update the candidate's entry in `state/long_form_queue.json` with `image_path`, set status to `image_sourced`.

## Never do
- Never fetch, download, or reuse a real photo (Pinterest, Google Images, stock sites requiring attribution/license you haven't verified) as the final background. Generation only.
- Never skip straight to Agent 3.2 without confirming the image actually matches the brief's mood — a mismatched image undermines the whole video's aesthetic consistency.
