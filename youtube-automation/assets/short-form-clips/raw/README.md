**Known copyright status:** these clips originate from other creators' content (sourced via Pinterest). Per an explicit decision with the channel owner, no automated copyright-clearance gate is applied to short-form source footage — the accepted mitigation is that Agent 3.1 (Producer) must transform each clip (reframe/crop, speed/color change, original text overlays, and a swapped-in CC0 audio track) before publishing, rather than reposting as-is. This is a deliberate, documented risk acceptance, not an oversight. YouTube's Content ID system remains the real backstop; the channel owner has accepted the resulting claim/strike risk.

**Known visual artifact — do not "fix", the crop already handles it:** every clip in this folder has a "Download link in description" text card baked into the left portion of the frame for the clip's *entire* duration (confirmed 2026-07-27 by visually inspecting frame grabs from all 49 available clips, not just intros). This is because the real vertical-video content is centered in the wider 1920x1080 canvas with padding/branding on the left (and empty space on the right) — a repost-template artifact from the original source. `scripts/short_form_transform.py`'s default center-crop to 9:16 (`crop=min(iw,ih*9/16):min(ih,iw*16/9)`, which crops the horizontal center of the frame) lands almost exactly on the real content region and excludes the watermark by construction — verified visually against multiple clips and the already-published sf_002 video. If a future change to the crop logic ever moves the crop window off-center, re-check for watermark bleed before trusting the output.

**Content scope — read before scripting an angle around this footage:** this pool is genuinely *only* luxury-lifestyle content: supercars, yachts, jetskis, cash, hot air balloons, pools, private jets/travel, city/night skylines. There is **no** literal library/book/candlelight/academic footage, no gym/workout footage, no literal "reading alone" imagery — nothing outside the luxury-lifestyle/travel category. Confirmed 2026-07-27 when `sf_003` (a "dark academia, reading alone" angle) was quarantined after Agent 0 visually reviewed both a full contact sheet of the pool and the produced video: no clip-selection heuristic can fix a fundamental content-category mismatch. **Agent 1.1 (Trend Scout) should weight future short-form angles toward concepts this footage can actually support** (wealth/cars/travel/luxury-mindset framings) rather than scripting angles like "gym discipline" or "quiet library reading" that this specific clip pool has no real material for — those either need new footage sourced first, or should stay as long-form/other-format ideas instead.
