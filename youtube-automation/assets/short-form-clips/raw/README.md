# Short-form raw clips

Source: user-supplied Google Drive folder "60 luxury lifestyle clips.zip (Unzipped Files)".
58 of the original ~60 clips were retrievable; 2 files (`11.mp4`, `49.mp4`) are not present in the source folder.
9 larger clips (6.6MB–13MB) could not be pulled through the Drive download tool in this session due to a size/timeout ceiling and are still missing: `4.mp4`, `22.mp4`, `33.mp4`, `34.mp4`, `40.mp4`, `42.mp4`, `44.mp4`, `46.mp4`, `59.mp4`.

**Known copyright status:** these clips originate from other creators' content (sourced via Pinterest). Per an explicit decision with the channel owner, no automated copyright-clearance gate is applied to short-form source footage — the accepted mitigation is that Agent 3.1 (Producer) must transform each clip (reframe/crop, speed/color change, original text overlays, and a swapped-in CC0 audio track) before publishing, rather than reposting as-is. This is a deliberate, documented risk acceptance, not an oversight. YouTube's Content ID system remains the real backstop; the channel owner has accepted the resulting claim/strike risk.

**Known visual artifact — do not "fix", the crop already handles it:** every clip in this folder has a "Download link in description" text card baked into the left portion of the frame for the clip's *entire* duration (confirmed 2026-07-27 by visually inspecting frame grabs from all 49 available clips, not just intros). This is because the real vertical-video content is centered in the wider 1920x1080 canvas with padding/branding on the left (and empty space on the right) — a repost-template artifact from the original source. `scripts/short_form_transform.sh`'s default center-crop to 9:16 (`crop=min(iw,ih*9/16):min(ih,iw*16/9)`, which crops the horizontal center of the frame) lands almost exactly on the real content region and excludes the watermark by construction — verified visually against multiple clips and the already-published sf_002 video. If a future change to the crop logic ever moves the crop window off-center, re-check for watermark bleed before trusting the output.
